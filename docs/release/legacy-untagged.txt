# Published versions that had no git tag, because they were published before
# anything pushed tags.
#
# `changeset publish` printed "Creating git tags… Created git tags." on every
# release while nothing pushed them, so twelve versions sat on npm with no tag
# on origin. `release.yml` pushes tags from now on, but a fix cannot
# retroactively create what was dropped — `scripts/backfill-tags.sh --push`
# did that on 2026-09-16, at the commits that introduced each version.
#
# `verify-published.sh` skips a tag named here — and FAILS if one named here
# actually exists, so the file cannot outlive its purpose. The list below is
# empty and every version the repository declares is now tagged on origin, so
# the gate runs against the remote and nothing is exempt from it.
#
# This was debt, written down. The empty list is the point: it is kept rather
# than deleted so the next person to find a tag missing knows this already
# happened once, and how it was repaid.
