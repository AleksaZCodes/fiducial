### The attribution notice

CC BY 4.0 § 3(a)(1) requires that you retain, in any reasonable manner based on
the medium, the creator's name, a copyright notice, a licence notice, a
disclaimer notice, and a link to the work. § 3(a)(1)(B) requires that you
indicate whether you modified it. This project modified it, as recorded above.

**Put the notice somewhere a reader can reach it** — a colophon, an about page,
or the site footer. A licence file in the source tree satisfies a developer
reading the repository; it does not satisfy the licence for a published site,
because a visitor never sees it.

Suggested wording:

> Arrow marks from the Hand Drawn Arrows Doodle Set, used under
> [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and modified.

### The creator's name is missing, and that is a live problem

CC BY 4.0 § 3(a)(1)(A)(i) requires the creator's name **if supplied**. The
Figma Community page returns 403 to every automated request made from this
repository, and the downloaded archive contains no licence file, no README, and
no metadata naming the author. So the name has not been verified, and it is not
written here rather than guessed: an attribution naming the wrong person is
worse than one that is incomplete, and it is a fresh wrong done to two people.

**Before this ships anywhere public, open the source URL in a browser, read the
author's display name off the page, and fill in the Creator row above and the
notice on the site.** That is a two-minute task that nothing in this repository
can do for you.

If the creator turns out not to be named on the page at all, the requirement is
discharged, and this section should be replaced with a sentence recording that
the page named no author on the date you checked.
