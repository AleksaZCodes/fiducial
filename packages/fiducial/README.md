# @fiducial/fiducial

> Declare each fact once. Derive every artifact from it.

**Fiducial** is a cross-domain build system for products that span web, firmware, electronics,
mechanical, simulation, and content — at the quality and pace that normally needs a team, run
by one person working with agents.

See the [full design](https://github.com/AleksaZCodes/fiducial) for the mission, stack, and
build order.
