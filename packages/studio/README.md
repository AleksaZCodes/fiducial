# @fiducial/studio

The workbench for Fiducial declarations: a **static app** that edits a product
through a *source*.

| Source | Where files live | Can do |
|---|---|---|
| `fid studio` (loopback) | the working copy on disk | everything: dashboard, forms, derive, live preview |
| GitHub | a repository branch, over the REST API | edit and commit from any browser; preview a deployed URL |

The UI asks a source what it can do and hides the rest, so it never branches on
which kind it has.

## Run it

```bash
pnpm --filter @fiducial/studio build
fid studio            # prints http://127.0.0.1:7777/#token=…
```

`fid studio` finds the built app in `node_modules/@fiducial/studio/dist` or
`packages/studio/dist`, or takes `--app <dir>`. The token is in the URL
fragment, which a browser never sends to a server.

For development, `pnpm --filter @fiducial/studio dev` plus
`?api=http://127.0.0.1:7777` in the page URL (the loopback server answers only
`localhost`, so run both on one machine).

## Layout

- `src/lib/types.ts` — the `Source` contract.
- `src/lib/sources/` — `local` and `github`.
- `src/lib/toml.ts` — edits TOML **text** in place, keeping comments and order.
- `src/lib/schema.ts` — turns the JSON Schema into the form's field kinds.
- `src/fiducial.schema.json` — generated by `fid studio schema`; a Rust test
  fails when it is stale.
- `src/components/ui/` — shadcn components as the CLI wrote them.
