# @fiducial/studio

The workbench for Fiducial declarations: a **static app** that edits a product
through a *source*.

| Source | Where files live | Can do |
|---|---|---|
| `fid studio` (loopback) | the working copy on disk | everything: dashboard, forms, derive, live preview |
| GitHub | a repository branch, over the REST API | edit and commit from any browser; preview a deployed URL |

The UI asks a source what it can do and hides the rest, so it never branches on
which kind it has.

## Run it

```bash
pnpm --filter @fiducial/studio build
fid studio            # prints http://127.0.0.1:7777/#token=…
```

`fid studio` finds the built app in `node_modules/@fiducial/studio/dist` or
`packages/studio/dist`, or takes `--app <dir>`. The token is in the URL
fragment, which a browser never sends to a server.

For development, `pnpm --filter @fiducial/studio dev` plus
`?api=http://127.0.0.1:7777` in the page URL (the loopback server answers only
`localhost`, so run both on one machine).

## Layout

- `src/lib/types.ts` — the `Source` contract.
- `src/lib/sources/` — `local` and `github` (commits or pull requests).
- `src/lib/editor.ts` — where the content editor is reached, per editor and source.
- `src/lib/topology.ts` — the topology as nodes and buses, its layout, and every edit as a change to `topology.toml`.
- `worker/` — the sign-in Worker.
- `src/lib/toml.ts` — edits TOML **text** in place, keeping comments and order.
- `src/lib/schema.ts` — turns the JSON Schema into the form's field kinds.
- `src/schemas/*.schema.json` — generated by `fid studio schema <name>`; a Rust
  test fails when one is stale.
- `src/components/ui/` — shadcn components as the CLI wrote them.

## Sign in with GitHub

A browser cannot finish GitHub's OAuth flow alone (the code exchange needs the
client secret), so `worker/` is a small Cloudflare Worker that does that one
step. Create a **GitHub App** (user tokens are limited to the repositories and
permissions you grant: Contents and Pull requests, read and write), then:

```bash
cd packages/studio/worker
# set GITHUB_CLIENT_ID and ALLOWED_ORIGINS in wrangler.toml, then:
wrangler secret put GITHUB_CLIENT_SECRET
wrangler deploy
```

Set the App's callback URL to `https://<worker>/callback`, and put the Worker's
URL in `studio.config.json` (`{ "authUrl": "https://<worker>" }`) next to the
built app. Without it, Studio asks for a fine-grained token instead.

## Not done

Drag-and-drop over shadcn blocks, per-pull-request preview URLs, forms for the
declarations that have no schema yet. The GitHub source and the
Worker are tested against mocks, not live GitHub. See the Studio section of the
repository `ROADMAP.md`.
